# CLAUDE — CHELTH BRAND IMPLEMENTATION RULES

Read this file before changing Chelth UI, marketing pages, emails, auth screens, or brand assets.

## Source of truth

Brand guidelines:
`docs/brand/CHELTH-BRAND-GUIDELINES.md`

Design tokens:
`docs/brand/CHELTH-DESIGN-TOKENS.md`

CSS tokens:
`src/styles/brand.css`

Canonical logo assets:
`public/brand/chelth/`

## Non-negotiable logo rule

The approved Chelth logo is the locked **Shift Mark**.

Do NOT:

- redraw it
- replace it
- generate an alternate mark
- recreate the wordmark with plain text where an approved lockup exists
- change its colors
- alter spacing inside the symbol
- apply gradients/effects not present in the approved asset
- create a substitute favicon

Always reference the canonical files from `public/brand/chelth/`.

## Visual direction

Chelth must feel:

- premium
- calm
- healthcare-native
- operational
- trusted

Chelth must NOT feel:

- AI-first
- futuristic
- neon
- overly glassmorphic
- like a generic SaaS template

## Implementation defaults

Product UI:

- off-white application canvas
- white working surfaces
- restrained borders
- minimal shadows
- teal for meaningful action/selection
- navy for hierarchy
- tables over card grids when information is operational/dense

Marketing:

- stronger typography
- selective photography
- alternating light and dark sections
- restrained use of mint
- outcome-led copy

## Language rule

Prefer:

- Fill shifts faster
- 3 shifts still need coverage
- Suggested workers
- Credential status
- Workforce overview

Avoid:

- AI-powered
- intelligent
- optimization engine
- next-generation
- revolutionary
- smart staffing

## QA gate

Before marking any Chelth UI/marketing task complete, verify:

1. Correct logo asset used.
2. Brand colors match tokens.
3. Typography follows Manrope/Inter split.
4. No unapproved gradients/glow effects.
5. Teal is not overused.
6. Product surfaces remain calm and operational.
7. Semantic colors indicate actual status.
8. Copy is outcome-led and not AI-centric.
9. Mobile layout preserves hierarchy.
10. No duplicate or improvised logo treatment was introduced.
