# Chelth Product Typography

This file is the product typography source of truth for Chelth application screens.

## Font families

### Display / Product Headings
**Manrope**

Use for:
- page titles
- major section headings
- large KPI values where applicable

### Product UI / Body
**Inter**

Use for:
- body copy
- sidebar/navigation
- filters
- tables
- buttons
- status chips
- metadata
- forms
- drawer content

## Rules

1. Do not choose fonts independently per page.
2. Do not replace Manrope or Inter without an explicit brand-system change.
3. Do not use arbitrary font sizes to visually force-fit components.
4. Prefer layout correction over shrinking typography.
5. Maintain the same hierarchy across Operations Overview, Shifts, Staffing Requests, Workforce, Credentials, Facilities, Notifications, and Settings.
6. Mobile may reduce page-title scale, but the font family, weight hierarchy, and relative scale must remain consistent.
