# Chelth Facilities — Locked Design Specification

## Screen

`Facilities`

Supporting copy:
`Manage facility relationships, staffing demand, and operational activity in one place.`

Primary action:
`Add Facility`

## Summary cards

- Active Facilities
- Open Requests
- Shifts This Week
- Needs Attention

No decorative mini charts.

## Main table

The canonical table includes:
- Facility
- Location
- Primary Contact
- Open Requests
- Upcoming Shifts
- Roles Used
- Status
- Last Activity
- row action

## Facility Details drawer

Tabs:
- Overview
- Requests
- Shifts
- Activity

Primary action:
`Create Request`

Secondary:
- `View Shifts`
- `Message Facility`

## Product role

Facilities is a healthcare staffing operations hub.

It should centralize:
- facility relationships
- current demand
- upcoming shifts
- common roles
- operational history

It is not a generic CRM.

## Canonical tone

Reliable.
Calm.
Operational.
Trusted.
Premium.
Healthcare-native.
Not AI-centric.
