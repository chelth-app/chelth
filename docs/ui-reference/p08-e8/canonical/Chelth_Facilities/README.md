# Chelth Facilities — LOCKED Interactive Reference

This package contains the approved Facilities screen and a lightweight interaction layer.

## Visual source of truth

`assets/chelth-facilities-locked.png`

The visual must not be redesigned.

## Demonstrated interactions

- Click any facility row → open Facility Details.
- Click `X` → close Facility Details.
- Closing the drawer expands the facility table into the freed width.
- Re-selecting a facility reopens the drawer.
- Summary cards behave as quick filters.
- Facility filters/search are interactive.
- Drawer tabs are interactive.
- Recent requests are clickable.
- `Add Facility` opens the add-facility flow.
- `Create Request` starts a request already scoped to the selected facility.
- `View Shifts` opens Shifts filtered to the selected facility.
- `Message Facility` opens the existing facility communication flow.
- Pagination controls are interactive.

The HTML uses screenshot hotspots only to demonstrate the interaction contract. Production must use real components and real Chelth data.
