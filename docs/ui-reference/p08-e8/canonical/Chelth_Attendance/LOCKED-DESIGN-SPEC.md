# Chelth Attendance — Locked Design Specification

## Screen

P0-E8-S8 — Attendance

## Page title

`Attendance`

Supporting copy:
`Verify check-ins, resolve exceptions, and track attendance across active shifts.`

## Summary cards

- Checked In Now
- Late / Missing Check-Ins
- Geofence Issues
- Completed Today

No decorative sparklines.

## Main surfaces

- Today's Attendance
- Attendance Exceptions
- Check-In Verification
- Recent Attendance Activity
- Attendance Details drawer

## Detail actions

- Approve Override
- Message Worker
- View Shift
- Mark Resolved

## Product role

Attendance is the operational verification layer between:
- scheduled shift
- worker presence
- facility location
- geofence verification
- timesheet preparation

It is not a generic punch-clock UI.

## Canonical style

Preserve the existing Chelth:
- app shell
- dark teal sidebar
- off-white content field
- navy typography
- mint/teal state system
- restrained status colors
- Manrope/Inter typography
- rounded operational cards
- calm premium healthcare-native tone
