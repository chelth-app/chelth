# Chelth Shifts — LOCKED Interactive Reference v2

This package contains the approved Shifts List and Calendar visuals plus an interaction-only HTML reference.

## Locked
Do not redesign the app shell, typography, colors, spacing, cards, filters, table, calendar grid, detail panel, status chips, or hierarchy.

## Interaction contract
- Existing List / Calendar controls switch views.
- Clicking a List row opens Shift Details.
- Clicking a Calendar shift block opens Shift Details.
- Clicking X closes Shift Details.
- When closed, the main work area expands into the freed width.
- Reopening the panel contracts the work area again.

The HTML uses transparent hotspots only to demonstrate behavior. Production must use real components and real data.
