# Chelth Shifts — Locked Design Spec

## Views
1. List
2. Calendar

Both use the same Chelth shell and Shift Details pattern.

## Visual source of truth

- `assets/chelth-shifts-calendar-locked.png`

## Do not change
- sidebar
- top bar
- typography
- brand colors
- spacing
- filters
- KPI tiles
- table structure
- calendar structure
- side-panel styling
- status-chip treatment

## Approved behavior
The detail panel is contextual and collapsible.
Closing it expands the main work surface.
Selecting another shift reopens it with that shift's data.

## Brand
Operational, calm, premium, healthcare-native, and not AI-centric.
