The Settings page must remain inside the canonical Chelth product system:
- approved Chelth logo

- existing global search and user header
- mint/off-white workspace backdrop
- Manrope + Inter typography
- existing card radius and spacing
- established form, toggle, button, status, and modal language

The HTML is an interaction/reference artifact, not production code.
