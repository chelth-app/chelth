# Chelth Settings — Locked Design Specification

## Page

`Settings`

Supporting copy:
`Manage workspace preferences, workforce policies, notifications, geofencing, billing, and security settings.`

## Main application shell

Must remain identical to the canonical Chelth shell.

## Settings sub-navigation

- Organization
- Team & Permissions
- Notifications
- Attendance & Geofencing
- Shifts & Scheduling
- Timesheets & Payroll
- Rates & Billing
- Integrations
- Security
- Workspace

## Organization section

Locked visible groups:
- Workspace Details
- Operational Preferences
- Brand / Identity

Primary action:
`Save Changes`

Secondary:
`Cancel`

## UI language

Use canonical:
- two-column form grids where appropriate
- simple select/input fields
- compact toggle rows
- white cards over pale mint/off-white workspace
- subtle borders
- restrained shadows
- teal primary actions
- red only for destructive actions

## Product tone

Settings should feel:
- operational
- controlled
- trustworthy
- premium
- administrative
- healthcare-native

It should not feel:
- like a generic SaaS template
- consumer-focused
- AI-centric
- visually experimental

## Typography

Use the canonical Chelth product typography system.

Do not choose independent type scales for Settings.
