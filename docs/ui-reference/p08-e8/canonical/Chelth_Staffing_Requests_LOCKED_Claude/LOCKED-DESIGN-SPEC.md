# Chelth Staffing Requests — Locked Design Specification

## Canonical visual

`assets/chelth-staffing-requests-locked.png`

This screen inherits the canonical design language established by the locked Shifts screen.

## App shell

Preserve:
- dark teal Chelth sidebar
- canonical Shift Mark / wordmark treatment
- top global search
- notifications
- signed-in user block
- white/off-white content surface
- restrained mint/teal background treatment
- Manrope display typography
- Inter product/UI typography

## Page

Title:
`Staffing Requests`

Supporting copy:
`Review, coordinate, and fulfill workforce requests across your facilities.`

Primary action:
`New Request`

## Summary cards

- New Requests
- In Progress
- Awaiting Facility
- Filled

Cards use:
- icon
- count
- concise supporting state

No decorative mini charts or sparklines.

## Main working surface

This screen is a request queue.

Do not add a Calendar view.

The table is the primary operational surface.

## Request Details

The right-side contextual drawer shows:
- request time
- status
- facility
- unit
- role + quantity
- need date + shift
- coverage progress
- requirements
- assigned workers
- suggested workers
- activity

Primary drawer action:
`Find Workers`

Secondary:
- `Contact Facility`
- `Edit Request`

## Interaction

Click request row → open Request Details.

Close drawer → expand queue into freed width.

Select another row → drawer returns with that request's data.
