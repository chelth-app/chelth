# Chelth Workforce — LOCKED Interactive Reference

This package contains the approved Workforce screen and a lightweight interaction layer.

## Visual source of truth

`assets/chelth-workforce-locked.png`

The visual must not be redesigned.

## Demonstrated interactions

- Click any professional row → open Professional Details.
- Click `X` → close Professional Details.
- Closing the drawer expands the workforce table into the freed width.
- Re-selecting a professional reopens the drawer.
- Summary cards behave as filter shortcuts.
- Filter controls are interactive.
- Drawer tabs are interactive.
- `Add Professional` opens the add-professional flow.
- `Assign to Shift` opens shift assignment.
- `Message` opens messaging.
- `View Credentials` opens credential details.
- Pagination controls are interactive.

The HTML uses screenshot hotspots only as an interaction reference. The production build must use real components and real Chelth data.
