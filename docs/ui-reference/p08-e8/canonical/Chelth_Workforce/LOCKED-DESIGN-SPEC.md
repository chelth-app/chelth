# Chelth Workforce — Locked Design Specification

## Screen

`Workforce`

Supporting copy:
`Manage availability, readiness, assignments, and workforce records in one place.`

Primary action:
`Add Professional`

## Summary cards

- Available Now
- On Assignment
- Needs Attention
- Credential Ready

No decorative progress/sparkline charts.

## Main table

The canonical workforce table includes:
- Name
- Role
- Contact
- Availability
- Current Assignment
- Credentials
- Next Shift
- Status
- row action

## Professional Details drawer

Tabs:
- Overview
- Credentials
- Assignments
- Activity

Primary action:
`Assign to Shift`

Secondary:
- `Message`
- `View Credentials`

## Product boundary

Workforce is an operational workforce directory.

Do not turn this page into:
- applicant tracking
- recruiting pipeline
- resume management
- generic HRIS

## Canonical Chelth language

Reliable.
Calm.
Operational.
Trusted.
Premium.
Healthcare-native.
Not AI-centric.
