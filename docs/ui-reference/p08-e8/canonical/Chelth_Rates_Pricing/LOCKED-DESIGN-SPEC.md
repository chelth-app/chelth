## Product role

Rates + Pricing manages rate-card rules and effective pricing configuration.

It is not:
- Payroll
- Invoicing
- financial forecasting
- revenue analytics

## Canonical style

Preserve Chelth:
- dark teal shell
- off-white workspace
- navy headings
- teal / mint status system
- restrained warning colors
- Manrope / Inter typography
- rounded operational cards
- premium healthcare-native visual tone
