# Chelth Worker Profile — Locked Design Specification

## Screen

P0-E8-S4 — Worker Profile

## Page role

This is the permanent operational record for one healthcare professional.

It is not:
- a recruiting profile
- a social profile
- an ATS candidate record

## Canonical page structure

Header:
- breadcrumb
- worker photo
- name
- active/status indicator
- role
- location
- internal worker ID
- Message
- Assign to Shift
- More

Summary:
- contact details
- employment/availability state
- rating/reference metric if supported by actual product
- hire/start date
- preferred facilities
- weekly availability

Tabs:
- Overview
- Credentials
- Assignments
- Schedule
- Timesheets
- Documents
- Activity
- Notes

Overview content:
- operational KPI cards
- Professional Information
- Skills & Preferences
- Next Scheduled Shift
- Credential Status
- Recent Activity

## Canonical tone

Reliable.
Calm.
Operational.
Trusted.
Premium.
Healthcare-native.
Not AI-centric.

## Visual system

Use the same:
- Deep Teal / Navy / Mint / Off-white system
- Manrope headings
- Inter UI typography
- card radius
- restrained shadows
- status chips
- interaction language

as the locked Chelth product screens.
