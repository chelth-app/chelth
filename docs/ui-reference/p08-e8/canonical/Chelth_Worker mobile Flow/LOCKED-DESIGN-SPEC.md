# Chelth Worker Mobile Flow — Locked Design Specification

## Screen package

P0-E8-S7 — My Shifts / Worker Mobile  
plus connected shift-details / attendance / timesheet handoff states.

## Covered sequence

1. My Shifts
2. Shift Details
3. Check-In / Check-Out
4. Timesheet Handoff

## Product role

This is the worker-facing mobile operational flow.

It should help the worker:
- understand upcoming work
- prepare for the shift
- arrive at the facility
- record attendance
- hand attendance into timesheets

It is not:
- a generic wellness app
- a generic chat app
- a consumer marketplace

## Canonical style

Use:
- exact Chelth branding
- approved logo direction
- navy / deep teal / mint / off-white palette
- Manrope-like display hierarchy consistent with Chelth
- Inter-like UI/body treatment consistent with Chelth
- calm, operational, premium visual tone

## Interaction intent

The worker should always know:
- the next action
- the next shift
- attendance status
- what is prefilled vs editable
- what still needs to be submitted
