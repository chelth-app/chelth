# Chelth Timesheets — Locked Design Specification

## Screen

P0-E8-S9 — Timesheets

## Page title

`Timesheets`

Supporting copy:
`Review worked time, attendance-derived hours, and timesheet approvals across your workforce.`

## Summary cards

- Pending Submission
- Needs Review
- Approved
- Needs Correction

No decorative sparklines.

## Main surfaces

- Current Timesheets
- Recent Timesheet Activity
- Timesheet Details drawer

## Detail actions

- Approve Timesheet
- Request Correction
- View Attendance
- View Shift

## Product role

Timesheets are the reviewable/approvable worked-time layer between:
- attendance
- shift
- worker
- facility
- later payroll/invoice workflows

Timesheets do not replace Attendance as location/time verification evidence.

## Canonical style

Preserve existing Chelth:
- dark teal app shell
- off-white workspace
- navy headings
- mint/teal operational states
- restrained warning colors
- Manrope / Inter typography
- rounded cards
- clean data tables
- calm premium healthcare-native tone
