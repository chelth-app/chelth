5. P2 — SHOULD FIX
------------------
P2-1  Row-action glyph inconsistency.
      - The canonical "⋮" is used on Shifts, Workforce, Facilities and
        Compliance.
      - "⋯" is used on Attendance and Timesheets. The locked doc allows
        these until their next pass.
      - Rates, Payroll and Invoices also use "⋯". Finance therefore
        extended the interim glyph rather than adopting the canonical
        one.
      Fix: switch the five to "⋮" (one prop each). Low risk.

P2-2  Record and settings action buttons are 36 px tall at phone widths.
      They are below the brand's 44 px mobile target. WCAG 2.2 target size
      (24 px) still passes.
      Examples at 375:
      - Shift record: Mark completed, Re-check readiness, Remove <worker>;
      - Worker record: Set inactive / suspended / terminated, Add
        discipline …;
      - Facility record: Mark suspended / ended / inactive / archived;
      - Payroll batch / Invoice draft: Mark reviewed, Cancel batch, Void
        draft;
      - Settings → Team: Assign role, Suspend, Remove; role select 36 px;
      - Settings → Payroll: Save payroll settings, Require a second
        approver;
      - Timesheet record: Recalculate from attendance;
      - My Credentials record: Stop sharing, Open document.
      Source: the shared InlineActionForm / small Button size.
      Fix: one shared change (min-h-11 below sm).

P2-3  Filter selects are 42 px at phone widths (all locked filter rows:
      Shifts, Timesheets, Workforce, Facilities, Compliance, Rates,
      Payroll, Invoices).
      Fix: a 2 px change in the shared filter control, to 44.

P2-4  "Recalculate from attendance" (Timesheet record → Approval) uses
      Button variant="ghost". It renders as plain text with no button
      chrome, which is not in the locked CTA hierarchy (J).
      Fix: the outlined secondary.

P2-5  Sidebar label truncation in the facility workspace: "Timesheet
      sign-off" shows as "Timesheet sign..." at the locked 214 px sidebar
      (every lg+ width).
      Fix: a shorter label ("Sign-off") or allow two lines. A product copy
      decision.

P2-6  Desktop table scroll regions overflow by a few pixels at 1280.
      Measured horizontal overflow:
      - Workers 25 px, Client facilities 25 px, Staffing requests 20 px;
      - Agency timesheets 6 px, Rate cards 7 px, Payroll batches 7 px,
        Invoice drafts 7 px;
      - Priced lines 67 px.
      "Timesheet entries" on the Timesheet record reports 320 px of
      overflow even at 1512. This region is not visible in the default
      view; it was measured as a scroll container, not seen as a visible
      defect.
      Headless Chromium uses overlay scrollbars. On platforms that always
      draw scrollbars (Windows, macOS with a mouse) these regions show a
      horizontal scrollbar for a few pixels: the same class of artifact
      fixed in A1.2 for tabs.
      At 1024 / 768 the overflow (150–360 px) is intended
      (scroll-in-region; no page overflow anywhere).
      Fix: tune column min-widths for 1280, or hide the bar until real
      overflow. Verify on a classic-scrollbar platform.

P2-7  Agency Attendance evidence page
      (/attendance/<id>/evidence, AAL2-gated) is on legacy primitives:
      no reference PageHeader, no `.chelth-locked`.
      It has low traffic, but it is reached from the locked Attendance
      record.

P2-8  Sign-up success state ("Check your email") uses a legacy
      `text-lg font-semibold` h2 and muted text inside the locked
      AuthPanel. This is a small typographic mismatch.

P2-9  Worker page-title casing is inconsistent: "My Shifts" (title case)
      against "My credentials" (sentence case). The worker Timesheets list
      also shows an agency back-link that My Shifts / My credentials do
      not.

P2-10 Git hygiene: the untracked
      docs/ui-reference/p08-e8/canonical/Chelth_Hero.zip is 21.7 MB and
      contains __MACOSX resource-fork files. A blanket `git add .` would
      commit it. Decide whether to ignore it, extract the needed assets,
      or keep it out of the repository.
