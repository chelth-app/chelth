7. SETTINGS MOBILE SUB-NAV RESULT
---------------------------------
File: settings/_components/settings-nav.tsx

Inspection: below lg the sub-navigation is a horizontal overflow-x: auto
row; from lg it is a static sticky column (lg:overflow-visible). Like
SectionTabs before A1.2, the row can show native scrollbar chrome on
platforms that always draw scrollbars.

Change (mobile row only):
- overflow-y hidden;
- scrollbar-width: none, and ::-webkit-scrollbar hidden.

The same proven approach as SectionTabs. overflow-x: auto is kept, so
touch, trackpad, wheel and keyboard scrolling still work, and the existing
"scroll the current section into view" behaviour is untouched. The row's
8 px padding keeps outset focus rings unclipped.

Desktop is unchanged: lg:overflow-visible resets both axes.

Asserted below 1024:
- overflow-x auto, overflow-y hidden, scrollbar-width none;
- when the row overflows it still scrolls (scrollLeft moves);
- the current section remains visible (existing check);
- axe clean.
The component was not converted to SectionTabs.
