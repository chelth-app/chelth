3. HEADER
---------
- "Attendance", with the reference subtitle wording adapted to the product
  ("clock-ins").
- The right side holds the real attendance-window control (form "Attendance
  window": from / to dates, Show, Today). It replaces the reference
  date-picker slot and uses the existing range parameters.
- There is no status dropdown: no status filter exists in the product.
- The back link was removed, as on the other locked pages.


4. ATTENDANCE KPIs (real counts, reference slots; each links to its section)
---------------------------------------------------------------------------
- Clocked In Now: clocked in or on break. "Across N facilities". Footer:
  the window.
- Needs Review: records with open exceptions. Footer: "N late · N missed",
  from the open exceptions in the window.
- Location Issues: outside-site-area / imprecise / unavailable exceptions in
  the window. Footer: "N outside · N imprecise or unavailable".
- Completed: clocked out. Footer: the number of pending correction requests.

The group is still named "Attendance summary".


5. FILTERS
----------
The real filter is the attendance window (from / to, up to 7 days; empty
means today at each facility).

The reference "All Statuses" filter is not offered: the product has no
status filter. No fake dropdown.


6. MONITORING TABLE (Scheduled Workers, in the Today's Attendance slot)
-----------------------------------------------------------------------
- REF_TABLE in a RefPanel with 42 px rows.
- Columns:
  - Clock-in: local time with zone;
  - Worker: initials avatar and a link to the record;
  - Facility: links to the shift;
  - Shift: local range;
  - Status: chip, plus an exception / correction line;
  - Location: derived clock-in result;
  - ⋯: Attendance Details.
- The selected row gets the teal accent when the drawer is open.
- The region is still named "Scheduled workers table".


7. ATTENDANCE STATES
--------------------
Product vocabulary only (ATTENDANCE_STATE_LABELS): Not started, Clocked in,
On break, Completed, Needs review.

Exceptions use ATTENDANCE_EXCEPTION_LABELS.

No reference-only states: Late, Missing, Verified and Geofence Review are
expressed through the real exception labels.


8. GEOFENCE / LOCATION SAFE PRESENTATION
----------------------------------------
Only derived results (GEOFENCE_RESULT_LABELS) appear anywhere on the list,
the drawer or the record summary: Inside site area / Outside site area /
Location too imprecise / Location unavailable / Not required.

- No coordinates, distance, device or map: these are not in the safe
  projection.
- Raw evidence stays on the existing AAL2-protected evidence route,
  reached from the record.
- The QA spec asserts that the drawer contains no latitude or longitude.

"Location Verification" panel (the Check-In Verification slot):
- a ring of the real clock-in location results in the window, with the
  centre showing the share of checked clock-ins inside the site area;
- legend counts beside it;
- a deliberate empty state when no location checks apply.


9. ATTENDANCE DRAWER (canonical; title "Attendance Details")
------------------------------------------------------------
- Identity: initials avatar, worker, state chip, shift date.
- Meta rows: facility · location; local range and zone.
- Tabs:
  - Overview: Check-In Information (clock-in / out, time on shift, status,
    location at clock-in / out) and Needs Attention (exceptions with
    open / under-review state, pending corrections, or a quiet "Nothing
    open").
  - Location: derived results and the evidence note.
- Actions: primary "Open attendance record"; secondary "View Shift".

Not offered:
- Approve Override and Mark Resolved: the real review actions (Acknowledge
  / Dismiss / Mark not worked) stay on the exceptions panel and the record,
  under ATTENDANCE_REVIEW.
- Message Worker: there is no messaging.

Canonical record arrangement:
- breadcrumb;

  chip and open-exception chip);
- SectionTabs (Summary, History, Exceptions, Adjust, Evidence; real sections
  only, capability-gated);

- History (append-only table, unchanged);
- Open exceptions (RecordList);
- Adjust;
- Evidence (AAL2 step-up unchanged).


11. EVIDENCE
------------

12. CORRECTIONS / EXCEPTIONS
----------------------------
- Correction Requests panel (the Recent Attendance Activity slot): the same
  CorrectionReviewForms, with an append-only note in the empty state.
- Attendance Exceptions panel: worker, site, exception chip, and the same
  Acknowledge / Dismiss / Mark not worked actions.
- The record History is unchanged and remains the append-only timeline.
- No destructive editing is implied.


13. FACILITY SAFE PROJECTION
----------------------------
Facility-facing attendance (staffing-request detail) was not touched. The
existing test still asserts it shows no coordinates. The agency attendance
route still returns 404 for facility users and workers.


14. RESPONSIVE BEHAVIOUR
------------------------
- 1280 / 768 / 412 / 375: no page-level overflow (asserted).
- Fixed: a 5 px overflow from the native date inputs. On phones the header
  control takes the full width and its inputs shrink.
- Tables scroll in their regions; panels stack below xl; the drawer is a
  full-height sheet on phones.


15. INTENTIONAL PRODUCT / DATA DIFFERENCES
------------------------------------------
- Not in the product: status filter, worker roles in rows, photos, a
  distance / device / map evidence summary in the list or drawer, Approve
  Override, Message Worker, Mark Resolved (as named), an attendance activity
  feed and a historical verification range.
- Drawer docking: the locked drawer docks without dimming at 1536 px and
  wider (a global lock). The 1512 px reference canvas therefore shows the
  modal with a dimmed page (screenshot 04). The drawer is narrower in the
  reference (314 px) than the canonical 387 px, which was kept.
- QA data: five day shifts, two clocked in after the start (real late
  clock-ins), no location checks configured (so the verification panel
  shows its empty state) and no corrections.
