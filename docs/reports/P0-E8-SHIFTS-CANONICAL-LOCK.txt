3. MAIN SHIFTS CHANGES
----------------------
- The page joins the locked system (.chelth-locked) with PageHeader
  variant="reference": "Shifts" and the subtitle "Plan, assign, and track
  shift coverage across facilities." The existing timezone rule is kept in
  the subtitle.
- Toolbar (form "Filter shifts") in the Facilities control geometry:
  - date range (List view only; the Calendar uses week navigation);
  - facility, status, Apply filters, Clear filters;
  - "+ Create shift" in the canonical primary CTA, revealing the existing
    create form at #create-shift.
  - There is no role filter or search: neither is supported by the list
    query.
- KPIs (region "Upcoming shifts"): Open Shifts, Pending, Confirmed and Not
  Fully Staffed. These are the existing real counts. They are now in the
  locked md tile with duotone icons. Open Shifts stays the status quick
  filter.
- List / Calendar segmented control (nav "Shift views"): two links,
  aria-current="page" on the active one.
  - Active: deep-teal gradient with a white icon and label.
  - Inactive: white, with navy text and a teal icon.
  - State is in the URL: ?view=calendar&week=YYYY-MM-DD; List is the
    default.
- Docked drawer: at 1536 px and wider the work area contracts
  (pr-[407px]) beside the canonical drawer.


4. LIST VIEW
------------
- The existing table (region "Shifts table") is on the locked table system
  (REF_TEXT.tableHead 600 on the tinted band).
- Columns are unchanged: Date & Time, Role, Facility (pin, unit, facility
  request and reference), Assigned Staff (initials avatar, +n), Credential
  Status, Confirmation (or Needs attention n), Coverage Status (or
  Relationship not active), Actions.
- Row action: the canonical "⋮".
- Selected-row treatment: teal inset rule and mint fill.
- Pagination (cursor) is unchanged. No photos.


5. CALENDAR VIEW
----------------
- Week grid (region "Weekly shift calendar"):
  - real shifts for Mon–Sun of the chosen week, using the same paginated
    query with a week window (page size 200) and the facility and status
    filters;
  - rows: assigned staff (from the real assignments, with that week's
    hours) plus "Open places" for shifts still needing staff (open with
    unfilled places, or draft / requested). Without assignment.view, a
    single "All shifts" row;
  - each shift sits on its facility-local date (localDate(startAt,
    timezone));
  - "today" is highlighted.
- Blocks:
  - compact, rounded and status-led: confirmed (green), pending (amber),
    open (red), requested (blue), completed / cancelled (neutral);
  - they show the time range and a short facility name, with a text legend
    so status is not shown by colour alone;
  - each block is a DetailDrawerTrigger that opens the canonical Shift
    Details drawer, with an accessible label naming the facility, role,
    date, worker and status.
- Toolbar: previous / Today / next week links, the week range title, and
  "Week view" as plain text. Only a week view exists, so there is no fake
  Week selector.
- Empty week: deliberate empty state.
- Below lg: the same data as a day-by-day agenda (list "Weekly shift
  agenda"). The desktop grid is not forced onto narrow screens.


6. SHIFT DRAWER
---------------
Canonical drawer (DetailDrawer width="profile"; docked at 1536 px and
wider, modal below; full-height sheet on phones):
- Summary card (reference): date, time and zone with a duration chip;
  facility and unit; role and code. Icon tiles throughout.
- Assigned Worker(s): 52 px initials avatar, name (+n), role · assignment
  status, and "n of m assigned · n accepted". If nobody is assigned: "No
  worker assigned" with the same counts.
- Status (chip and note) and Credential readiness (chip and note) rows.
- DetailsTabs:
  - Details (KeyValueList: facility, unit, role, workers needed, timezone,
    source, relationship, reference);
  - Notes (real internal notes from listShiftNotes, agency only);
  - Activity (real assignment events, ActivityTimeline).
- Actions (real only): "Assign Worker" (primary when staffable),
  "Offer shift" (when offerable), "Open shift".
- Not shown, because they don't exist: Send Reminder, Replace Worker, pay
  rate, phone numbers, photos.


7. SHIFT RECORD PAGE
--------------------
Canonical record arrangement:
- RecordPage; PageHeader variant="reference" (facility · discipline);
  breadcrumb; date · unit;
- status chips (ShiftStatusBadge, FillBadge "Partially filled · n of m",
  Relationship not active) with RecordMeta (source · classification);
- SectionTabs "Shift sections" (Details, Assigned workers, Assign,
  Attendance, Offers, Decisions, Notes; real anchors only);
- canonical panels.

Restyled panels:
- Assigned workers: RecordList rows with an avatar, assignment status,
  readiness and issue chips, block reasons and the cancel form.
  "Re-check readiness" sizes to its content.
- Assign a worker: eligibility explanation; "Eligible workers" RecordList
  (avatar, readiness, Assign); "Unavailable workers" disclosure (avatar,
  Unavailable chip, the reasons, "Try to assign").
- Offer shift and Offers: RecordList rows with an avatar, offer status,
  close reason and expiry, and Withdraw.
- Internal notes: a RecordList of notes plus the existing note form.
- Attendance, Assignment decisions, Manage shift and Classification: the
  existing content on locked panels and tables.

All forms, actions, ids and capability gates are unchanged.

13. REMAINING DIFFERENCES
-------------------------
- Docking: the references show the drawer docked. The locked drawer docks
  at 1536 px and wider, so at the 1448 reference canvas it opens as a
  modal; the docked state is shown at 1536.
- The reference "All Roles" filter and shift search are not offered: the
  list query does not support them.
- The calendar Week/Day selector is not offered: only a week view exists.
- "Shifts (71)" total count: the list is cursor-paginated, so the title
  shows "Shifts" without a total.
- Drawer: no Send Reminder, Replace Worker, pay rate, phone or photo (not
  in the product).
- The KPI "At Risk" slot is Chelth's real "Not Fully Staffed" count.
- Docked at 1536: KPI labels wrap (locked tile geometry).
