P0-E8-A1.4 — DESKTOP WORKSPACE GATEWAY SPACING REFINEMENT
=========================================================

Branch: p0-e8-visual-implementation (uncommitted)
Base:   18ad514, plus the uncommitted F1–A1.3 work

Scope: the /app workspace gateway on desktop (lg, 1024 px and wider) only.
This is presentation only: no route, auth, selection, creation, permission,
database or security change. No screenshots were saved to the repository.


1. SPACING CHANGE
-----------------
File: src/app/app/(personal)/page.tsx

- The gap between the two gateway columns went from lg:gap-8 (32 px) to
  lg:gap-6 (24 px). gap-6 is the existing spacing token that the frame and
  locked panels already use.
- The column split went from minmax(0,1.7fr) / minmax(320px,1fr) to
  minmax(0,1.8fr) / minmax(320px,1fr). The organisations column moves from
  about 63% to about 64%, inside the 63–65% target; the create panel is
  about 36%.
- Top alignment is unchanged (lg:items-start; both columns begin at the
  "Your organisations" line).
- The Create a new agency panel is unchanged: same surface, padding, h2,
  supporting line and form. It stays the secondary column.


2. ORGANISATION-CARD WIDTH ADJUSTMENT
-------------------------------------
- Two or more organisations: unchanged 2-up grid (sm:grid-cols-2, 16 px
  gap). The cards gain width from the narrower gap and the slightly wider
  column.
- Exactly one organisation, from lg only: the list is one column, capped
  at 560 px (lg:max-w-[560px] lg:grid-cols-1). A lone workspace now gets
  one comfortable card instead of half the column, but it does not stretch
  across the whole column.
- The card's internals are unchanged: tile, name, chips, role line and the
  Open workspace action.
