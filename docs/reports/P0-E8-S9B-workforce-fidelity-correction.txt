  right-aligned.

  ("No active assignment", "No upcoming shifts").
- Credentials (Overview preview and the Credentials tab):

  - the title 14.5 / 600 ink, wrapping to two lines (never truncated);
  - "Valid to {date}" or the requirement scope as the second line;
  - a 28 px semibold Requirement-met / Expires-soon / … chip;
  - "View all" goes to the record's #readiness-heading.

Requirement states come only from the readiness engine
(COMPLIANCE_REASON_LABELS). No client-side compliance is computed.

Actions:
- Primary "Open Worker Record": a deep-teal gradient, 48 px, 15 / 600
  white, an icon, and inner highlight plus lift.
- Secondaries "Readiness" and "View Credentials": white, a teal 35%
  border, 14 / 600 ink, teal-dark icons, and hover tint.
- Each secondary is shown only when the user can see that record section.

  eligibility is evaluated for that shift.
- There is no worker-first assignment flow to reuse safely, so "Open Worker

- Message is not offered (no messaging).
