- No Chelth table, column, constraint, policy, function body, trigger,
  RLS flag or anon / authenticated grant differs.
- Differences:
  (a) production default privileges and grants give `service_role` ALL on
      public tables / functions / sequences, where locally they are
      narrower. These are Supabase platform defaults. service_role

      Recommendation: no action now; note for hardening.

      `public.rls_auto_enable()` (SECURITY DEFINER, search_path pinned to

      safety net). It returns event_trigger, so it cannot be invoked as
      an RPC despite its default EXECUTE grants.
  (c) `pg_net` is absent in production (present locally). See section 16.
