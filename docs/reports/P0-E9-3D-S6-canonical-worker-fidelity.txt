2. DIFFERENCES FOUND AND CORRECTED IN S6
----------------------------------------
- Shift Details order: "Need help?" came between Requirements and Check In,
  and Accept / Decline came last. Changed to the reference order: the
  primary decision (Accept / Decline) and the attendance action now follow
  Requirements directly; "Need help?" is last.
- Checked-in row: the "Current Shift" text was squeezed beside the
  "Checked In" chip into four lines. The chip now sits beside the title,
  with time and role · unit on their own lines.
- The "Worked Time" heading broke over two lines beside two chips. The
  chips now sit beneath the heading.
- Action wording: the buttons said "Clock in / Clock out"; the reference
  says "Check In / Check Out". The visible label and accessible name now
  read "Check In at <facility>" / "Check Out at <facility>". Behaviour is
  unchanged; 14 test references were updated.
- (S2) Facility imagery: a hero and thumbnails, with the approved artwork
  as fallback, and a fallback when an image cannot be shown.


3. SILHOUETTE / TYPOGRAPHY / RHYTHM (assessed)
----------------------------------------------
- Silhouette: header 64 px (logo mark, agency, "Worker · name", initials);
  the content is a single phone column; the bottom navigation is 64 px with
  a teal current item and top rule. It matches the reference frame.
- Typography: navy Manrope headings (page h1 28 px on phones, cards
  16–20 px / 600), Inter body 13–15 px, slate secondary text, as in the
  reference.
- Tabs: a white rounded container with a mint active segment, like the
  reference's Today / Upcoming / Past.
- Cards: white, 14 px radius, teal hairline, soft navy depth; icon-led fact
  rows with teal line icons.
- CTAs: full-width 48 px deep-teal gradient primaries; outlined
  secondaries; a coral outline for Check Out (the reference's red outline).
- State density: one chip per state, semantic panels (success, info,
  warning) only for real states.

It reads as a dedicated mobile application, not a responsive admin site:
- no sidebar or table at any width;
- the column stays ≤ 576 px and centred at 768 / 1280 (S7 responsive
  tests).


4. HONEST DIFFERENCES THAT REMAIN (product truth)
-------------------------------------------------
- Facility photos appear only when the agency uploads one; otherwise the
  approved artwork is shown. No stock or generated photos.
- No map thumbnail: there is no map tile provider. The "Get directions"
  card opens the device's map app (destination only).
- No notification bell or profile photo: there is no notification centre or
  photo model. Unread attention lives in More and Messages.
- No "Home" tab: My Shifts is home; More holds Messages and account items.
- No pre-action "Within facility radius" ticks: the server decides at the
  action. The outcome is shown afterwards ("never claim before server
  confirmation").
- No break dropdown or notes on the handoff: break time is derived from
  attendance; timesheet notes are not supported and submission is weekly.
  The handoff links to the weekly timesheet.
- Facility contact: a role / desk label, never a personal name (domain
  invariant).
