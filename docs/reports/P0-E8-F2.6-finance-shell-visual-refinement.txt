3. TAB ACTIVE-STATE REFINEMENT
------------------------------
The cause of the "side borders": the global :focus-visible ring (2 px,
offset 2 px) on the focused tab.

- After moving between areas with the tabs, or when tabbing with the
  keyboard, the link keeps focus.
- The tab row is a horizontal scroll container (overflow-x: auto). It
  clips an outset ring at the top and bottom, which leaves only two hard
  dark vertical bars beside the tab.
- This was reproduced with real keyboard focus before the fix.

Fix (Finance nav only):
- The focus ring is drawn inside each tab (outline-offset −3 px, 6 px top
  radius).
- A keyboard user now sees a complete, unclipped rounded ring. There are no
  stray side bars, and nothing is shown after a mouse click.

Active cue (locked SectionTabs treatment, unchanged):
- a 3 px Chelth-teal underline;
- 600 weight;
- dark ink (chelth-navy);
- aria-current="page".

Inactive tabs: 500 weight, slate-500, with a darker ink hover.

No pills, no boxes, no new font or tokens.


4. SPACING CHANGES
