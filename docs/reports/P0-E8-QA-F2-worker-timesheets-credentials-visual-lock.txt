6. READINESS TREATMENT
----------------------
The legacy flat grey ReadinessPanel block is replaced on this page by a W1
readiness card. The shared ReadinessPanel is unchanged: the agency Worker
record still uses it.

The card shows:
- a compliance tile;
- h2 "Readiness at <agency>" (20 / 600) and one supporting line;
- the existing ReadinessBadge (Ready / Action required / Not eligible).

Each engine item is one row:
- the credential name (15 / 600 ink);
- "Valid to Nov 13, 2027" for met items or "Expires …" for issues, plus
  "Facility requirement" where scoped;

  complianceTone.

Issues are listed before met items, in engine order. The "✓" text glyph
is gone.

Data:

  evaluate_worker_compliance), unchanged.
- Nothing is recomputed on the client.


7. DATE FORMATTING CHANGES
--------------------------
Raw ISO dates are removed from every worker-facing credential view:
- readiness rows;
- credential cards;
- the version rows on the record (issue and expiry).

All of them use formatCalendarDate ("Nov 13, 2027"), which formats a
calendar date in UTC so the day never shifts. Stored values and timezone
logic are unchanged.

Verification timestamps keep the existing en-GB medium date-time, matching
the locked agency Credential record.
